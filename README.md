# Structural Transformation of Electoral Politics in Uttar Pradesh (2002–2022)

An Integrated Institutional and Econometric Analysis

A study of electoral change in Uttar Pradesh combining institutional political economy with constituency-level econometric analysis, including fractional logit, quantile regression, mixed-effects models, and event studies.
